## A. MUST FIX

### F-001 · Normal upgrades overwrite unowned Copilot and Gemini commands

**P1 · High confidence · Fork-introduced migration regression.** `src/specify_cli/integrations/_command_upgrade_layout.py:16–21`, `_preflight_native_skills`, excludes both custom setup implementations and TOML rendering. `integration_upgrade` at `src/specify_cli/integrations/command_upgrade.py:89–96` scans old manifest keys. A *new* destination therefore escapes both guards. `TomlIntegration.setup` at `src/specify_cli/integrations/base.py:1759–1762` and `write_file_and_record` at lines 986–992 overwrite and claim the file. Copilot delegates to the standard writer after its own setup (`src/specify_cli/integrations/copilot/__init__.py:792–795`). The nonforced preservation contract is in `docs/fork-workflow.md:211–214`.

**Reproduction.** With the baseline wheel run `specify init project --integration gemini --script ps --ignore-agent-tools --non-interactive`. Add a project-specific prompt at the previously absent `.gemini/commands/speckit.deployment.toml`. With the fork wheel run `specify integration upgrade gemini`. The independent repeat returned 0, changed SHA-256 `ea770a1f…237b491b` to `f9000eda…0f83d06ca` and claimed the file in the manifest. Default Copilot reproduced the same loss at `.github/skills/speckit-deployment/SKILL.md`. No force flag or failure occurred. Upstream had no deployment command in either slot. The native-skills conflict regression at `tests/workflows/test_fork_workflow_install.py:516–530` uses Codex.

**Correction and regression.** Use existing destination calculations for every renderer before writing. On collision require a named conflict, byte-identical user file and unchanged manifests. Retry after the user moves the file should succeed. Include the two demonstrated adapters and other command-file formats.
